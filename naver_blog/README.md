# naver_blog — 네이버 블로그(lovuysy) 경험 기반 반자동 운영

직접 다녀온 곳의 **사진 + 메모**만 넣으면 내 말투로 쓴 원고, 키워드·제목 후보, 정리된 사진,
예약발행 시간까지 만들어 줍니다. 마지막 확인과 붙여 넣기만 직접 합니다 (글당 2~3분).

네이버 로그인이나 자동 게시는 하지 않습니다. 네이버 블로그 글쓰기 API는 종료됐고,
로그인 봇은 약관 위반이라 블로그가 검색에서 제한되거나 계정이 막힐 수 있습니다.

## 설치 (내 PC에서)

```bash
pip install -r naver_blog/requirements.txt      # 아이폰 HEIC 사진이면 pillow-heif 도
echo "ANTHROPIC_API_KEY=sk-ant-..." > naver_blog/.env
python -m naver_blog learn-style                 # 기존 글로 내 말투 학습 (처음 1번)
```

네이버 검색 API 키(`NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`)를 같은 `.env` 에 넣으면
상위 글 제목을 참고해서 겹치지 않는 제목을 만듭니다. 없어도 동작합니다.

## 글 하나 올리기

```bash
python -m naver_blog new 2026-11-02-논현-효도치킨   # inbox 에 폴더 생성
# → naver_blog/inbox/2026-11-02-논현-효도치킨/ 에 사진을 넣고 memo.txt 채우기
python -m naver_blog draft                          # 원고 생성 → 미리보기가 브라우저로 열림
```

미리보기(`naver_blog/out/<폴더>/post.html`)에서:

1. **확인할 것** — 빨간 항목(메모에 없는 가격 등)을 고칩니다.
2. **제목 후보** — 규칙을 통과한 것만 보입니다. 하나 복사.
3. **본문 텍스트 복사** → 네이버 글쓰기에 붙여 넣고 `[사진 01]` 자리에 `photos/` 의 같은 번호 사진을 올립니다.
4. 장소(지도) 추가, 태그 붙여 넣기 → **예약 발행**(추천 시간 표시됨).
5. 발행된 뒤 `python -m naver_blog sync` → RSS로 확인해서 발행 기록.

`python -m naver_blog list` 로 예약 대기열을 봅니다. 예약 시간은 `config.json` 의 `publish_slots`
(기본: 화·금 19:00, 일 11:00)에서 비어 있는 가장 빠른 칸을 추천합니다.

## 자동으로 해 주는 것

| 단계 | 내용 |
|---|---|
| 말투 | 기존 글을 읽고 말투·줄바꿈·자주 쓰는 표현을 규칙으로 정리 (`data/style.md`) |
| 키워드 | 동네 + 실제 먹은 메뉴/실제 상황으로 세부 키워드 선택. 메모에 없는 조건(주차, 데이트 등)이 들어간 키워드는 고르지 않음 |
| 사진 | 촬영 시각순 정렬, 1600px로 축소, **위치정보(GPS) 등 메타데이터 삭제**, `키워드-01.jpg` 파일명 |
| 원고 | 사진을 보고 순서에 맞게 배치, 메모에 있는 사실만 사용 |
| 점검 | 메모에 없는 숫자·가격, 확인 안 되는 문장, 안 쓴 사진, 과장 제목("무조건", "인생 맛집"), 상위 글 베끼기 |
| 협찬 | memo.txt 의 `협찬:` 에 받은 것을 적으면 맨 위에 경제적 이해관계 표시 문구를 넣음 |

## 원칙

- 글의 사실은 **memo.txt와 사진뿐**입니다. 가 보지 않은 곳, 먹지 않은 메뉴는 쓰지 않습니다.
- `inbox/`, `out/`, `data/` 는 git에 올라가지 않습니다 (사진·메모 보호).
