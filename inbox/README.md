# 피클 인계함 (inbox)

피클(또는 사람)이 여기에 초안·아이디어를 `.md`로 넣으면, 클로드 파이프라인이
10인 검수를 통과한 완성본으로 발행합니다. 처리된 파일은 `done/`으로 옮겨집니다.

## 피클에게 시키는 말 예시
> 「예약 문자 정리 자동화」 주제로 블로그 초안 메모를 써서
> deadletter 저장소 inbox/ 폴더에 날짜.md 로 커밋해줘.
> 첫 줄은 제목, 그 아래는 꼭 다룰 내용 메모.

## 파일 형식
```
---
title: 제목
category: ai-automation   # 없으면 자동 추정
---
무엇을 다룰지 메모 (숫자·출처·주의점)
```

실행: `.github/workflows/inbox-publish.yml` (30분마다) 또는 딸깍 협업 방에서 "피클 초안 발행".
