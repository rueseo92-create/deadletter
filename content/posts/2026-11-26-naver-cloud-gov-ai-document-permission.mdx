내가 열 수 없는 급여 파일을 사내 AI가 대신 읽고 요약해 준다면? 폴더 권한은 멀쩡한데 AI가 뒷문이 되는 장면이죠. 네이버클라우드는 52개 공공기관이 쓰는 네이버웍스에 이미지 생성 기능을 붙였어요. 같은 업데이트에서 문서 서비스 '페이지(Page)'의 AI는 사용자에게 열람 권한이 있는 문서만 참조하게 됐고, 보안 스페이스는 AI 참조 대상에서 통째로 빠졌어요. 포스터 기능보다 이쪽이 AI를 들이려는 회사에 더 쓸모 있는 소식입니다. (출처: 테크월드)

## 포스터 기능 옆에 붙은 업데이트: 52개 기관 네이버웍스에서 바뀐 것

네이버클라우드(대표 김유원)는 26일, 범정부 AI 공통기반의 개발 도구 'CLOVA Studio for GOV'에 이미지 생성 모델을 적용했다고 밝혔어요. 이 모델은 범정부 지능형 업무관리 플랫폼 '온AI'의 공식 협업툴인 네이버웍스에 탑재됐습니다. (출처: AI타임스)

네이버웍스를 쓰는 52개 기관에는 행정안전부, 과학기술정보통신부, 법무부 등 25개 중앙부처가 포함돼요. 나머지 52 − 25 = 27개 기관이 어디인지는 기사에 나오지 않아요. (출처: 테크월드)

| 바뀐 것 | 내용 |
|------|------|
| 이미지 생성 | 포스터·카드뉴스·배너 템플릿 선택 → 내용과 원하는 이미지 형태 입력 → 결과물 수정. 정책 홍보물, 행사 안내용 |
| CLOVA Studio for GOV | UI 개선, MCP 서버 연동, 에이전트 개발 실습 환경과 관리자 모니터링 강화 |
| 페이지(Page) | AI 참조 범위를 사용자 권한과 보안 등급에 맞춤 (아래에서 자세히) |
| EASY | 한글·PDF·영수증·스캔 문서에서 정보 추출, 공문 정리·자료 취합·회의 후속 처리 템플릿, 공공데이터 연동 |

(출처: AI타임스, 테크월드)

## AI가 읽는 범위를 권한에 묶은 이유

페이지에는 권한 설계가 하나 더 들어갔어요. 작성 중인 문서는 작성자만 열람하고, 완성한 뒤에 공유하는 구조입니다. (출처: 테크월드)

여기부터는 제 판단이에요. 사내 문서를 참고해 답하는 AI라면 권한 설계가 이미지 기능보다 먼저다. 폴더에 잠금을 걸어 둬도 AI가 그 안의 문서를 요약해 아무에게나 내보내면 잠금은 장식이 되니까요. 초안도 마찬가지예요. 확정되지 않은 숫자가 동료의 AI 검색에 걸려 돌아다니는 일은 막아야 하죠.

한 줄로 줄이면 이렇습니다. 이미지는 갈아타면 되지만 권한은 갈아엎어야 한다. 이미지 도구는 마음에 안 들면 다른 서비스로 옮기면 그만이에요. 권한은 다르죠. 이미 쌓인 문서마다 공유 범위를 다시 정해야 하고, 그 사이 AI가 답변으로 내보낸 내용은 회수할 수 없어요.

### 산림청처럼 자기 데이터를 붙이는 순간 권한 문제가 커진다

산림청은 범정부 AI 공통기반에 자체 산림 데이터를 결합해 '데이터기반 e-푸른샘'을 만들었어요. 별도 GPU나 AI 모델을 구축하지 않고 5개월 만에 서비스를 열었고, 직원들은 산사태 업무지원 AI와 소나무재선충병 현장조사 지원 AI도 직접 만들었어요. (출처: 테크월드)

네이버클라우드에 따르면 서비스 개시 후 한 달 동안 AI 분석 리포트 활용은 1398건이에요. 독립적으로 검증된 수치는 아닙니다. 한 달을 30일로 잡으면 1398 ÷ 30 ≈ 46.6건, 하루 약 47건꼴이에요. 이용자 수가 공개되지 않아 많은지 적은지는 판단할 수 없어요.

이 사례가 권한 이야기와 이어지는 지점은 따로 있어요. 현업 부서가 자기 데이터를 붙이고 직원이 직접 AI를 만들기 시작하면, AI가 닿는 데이터가 늘어나는 만큼 관리할 권한도 늘어납니다. 기능 확장 속도가 빠를수록 권한 설계를 먼저 깔아 둬야 하는 이유죠.

## 우리 회사에서 해 볼 권한 점검 4단계

매니저가 사내 AI에 '이번 달 근무 일정 정리해 줘'라고 물었는데 답변에 직원 급여표 내용이 섞여 나온다고 해 볼게요. 이런 일은 AI 자체보다 원래 느슨했던 폴더 권한이 드러나서 생기는 경우가 많아요. 그래서 점검은 AI가 아니라 폴더에서 시작합니다.

### 1단계: 전체 공개 폴더 찾기

- 구글 드라이브: 파일이나 폴더의 공유 창에서 '일반 액세스' 항목을 봅니다. '링크가 있는 모든 사용자'나 조직 전체 공개로 돼 있으면 점검 대상이에요. 하나씩 여는 방식은 작은 팀에서나 가능합니다. 조직 단위 목록은 구글 워크스페이스 관리 콘솔의 감사·보고서 기능에서 볼 수 있는데, 관리자 권한이 필요하고 메뉴 이름은 요금제와 시기에 따라 다를 수 있어요.
- MS 365(셰어포인트·원드라이브), 네이버웍스 드라이브: 공유 범위 확인 화면과 관리자용 보고서 이름이 도구마다 달라 여기서 특정하지 않습니다. 관리자 도움말에서 '공유 현황', '외부 공유' 같은 키워드로 찾아보세요. 역시 관리자 권한이 필요할 수 있어요.

### 2단계: 점검표에 적기

| 폴더명 | 공개 범위 | 민감 문서 여부 | 조치 |
|------|------|------|------|
| 예) 매장 운영 공유 | 전 직원 | 급여표 1건 | 인사 전용 폴더로 이동 |
| | | | |

급여, 계약서, 거래처 단가, 작성 중인 초안이 전체 공개 폴더에 섞여 있지 않은지가 핵심이에요.

### 3단계: 판매처에 그대로 보낼 질문

> 1. 검색·답변 시 사용자별 문서 접근 권한을 실시간으로 반영하나요?
> 2. 권한을 바꾸면 AI 답변에 반영되기까지 시간이 걸리나요? 걸린다면 얼마나 걸리나요?
> 3. 특정 폴더나 공간을 AI 참조 대상에서 통째로 빼는 설정이 있나요?
> 4. 작성 중인 초안이 다른 사람의 AI 검색 결과에 나오지 않게 할 수 있나요?
> 5. AI가 어떤 문서를 참조했는지 관리자가 기록으로 볼 수 있나요?

### 4단계: 더미 문서로 누수 테스트

1. '테스트_급여표' 같은 가짜 문서를 만들고 가짜 금액(예: 9,876,543원)을 넣습니다. 실제 민감 정보는 쓰지 마세요.
2. 이 문서를 관리자만 열 수 있는 폴더에 둡니다.
3. 그 폴더 권한이 없는 테스트 계정으로 AI에 '테스트_급여표에 적힌 금액 알려줘', '이번 달 인건비 총액 정리해 줘'처럼 물어봅니다.
4. 가짜 금액이 답변에 나오면 권한 연동 실패. 권한을 바꾼 뒤 답변에 반영되기까지 걸린 시간도 함께 적어 두세요.

## FAQ

### Q1. 일반 기업도 이 기능을 쓸 수 있나요?

이번 발표의 대상은 범정부용 CLOVA Studio for GOV와 온AI 네이버웍스예요. 민간 버전 적용 여부와 요금은 확인되지 않았어요. 네이버클라우드에 문의한다면 세 가지를 물어보세요. 민간 네이버웍스·클로바 스튜디오에 같은 기능이 들어가는지와 그 시점, 요금, 페이지처럼 사용자 권한을 따르고 보안 공간을 AI 참조에서 빼는 설정이 민간 버전에도 있는지.

### Q2. MCP 서버 연동은 뭔가요?

MCP(모델 컨텍스트 프로토콜)는 AI가 외부 데이터나 서비스와 연결되도록 해 주는 연결 규격이에요. (출처: AI타임스) 내부 시스템마다 연결 방식을 따로 만들지 않고 정해진 규격으로 붙일 수 있다는 게 일반적인 장점입니다. 이번에 어떤 서비스가 연결되는지는 기사에 나오지 않아요. 연결이 늘면 AI가 닿는 데이터도 늘어나니, 이 역시 권한 점검 대상이에요.

### Q3. 이미지 기능만 당장 필요하면 뭘 쓰면 되나요?

캔바(Canva)나 어도비 익스프레스(Adobe Express) 같은 디자인 도구에도 템플릿과 AI 이미지 기능이 있어요. 요금은 각 서비스 공식 페이지에서 확인하세요. 사내 문서와 연결하지 않는 도구라면 위의 권한 점검 부담도 상대적으로 작습니다.
