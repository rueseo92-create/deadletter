질문 3개 중 2개가 4점을 넘고 한도 안내에도 막히지 않았다면, 결제 버튼은 누르지 않는다. 이 글은 그 판정을 내릴 채점표를 준다. 결제하고 일주일 뒤 '무료 때랑 뭐가 다르지?' 싶어지는 상황을 막는 게 목적이다.

먼저 밝혀 둔다. 퍼플렉시티 AI를 직접 돌려 본 결과는 아니다. 세로AI는 작성 시점에 공식 요금, 한도, 메뉴 위치를 확인하지 못했다. 요금표는 바뀌어도 내 질문 3개는 계속 쓸 수 있으니, 숫자 대신 방법을 쓴다.

> 같은 질문 3개를 무료로 돌려 15점 채점표로 매기고, 유료가 필요하다고 나올 때만 결제 직전 공식 페이지에서 7가지를 확인하세요.

## 세로AI 테스트: 비교용 질문 3개를 AI에게 짜게 하기

이 테스트로 만든 건 퍼플렉시티에 넣을 질문 세트와 채점 기준이다. 세로AI는 Claude Sonnet 5.5로 아래 프롬프트를 실행했다. 다른 AI에서도 같은 결과가 나온다는 보장은 없다.

> 프롬프트(줄임): 검색형 AI의 답변 품질을 비교할 질문 3개를 설계해 줘. 최신 정보형, 여러 자료 비교형, 답이 정해진 사실 확인형을 하나씩. 질문마다 '좋은 답의 기준'을 한 줄 적고, 출처 링크를 확인할 항목 5가지를 표로 정리해. 요금이나 한도 숫자는 쓰지 마.

받은 질문은 이랬다.

- 최신 정보형
  - 질문: 가장 최근 한국은행 기준금리 결정의 내용과 배경, 발표 날짜는?
  - 좋은 답: 정확한 날짜, 1차 출처, 정보 기준 시점을 밝힌다.
- 비교형
  - 질문: 재택근무가 생산성에 미치는 영향을 두고 학술 연구, 언론 보도, 기업 사례는 각각 어떤 결론을 냈나?
  - 좋은 답: 자료 유형별로 나누고, 엇갈리는 이유를 짚고, 한쪽으로 단정하지 않는다.
- 사실 확인형
  - 질문: 대한민국의 수도와 현행 헌법 시행 시기는?
  - 좋은 답: 서울, 1988년 2월 25일을 군더더기 없이 제시한다.

진짜 쓸모는 질문 3개가 아니라 출처 체크리스트의 한 줄, '본문 내용 일치'에 있었다. 답의 핵심 주장을 링크 본문에서 직접 찾아보라는 항목이다. 링크가 붙어 있어도 본문에 그 주장이 없으면 출처는 장식일 뿐이다.

반대로 가장 약한 고리는 사실 확인형이다. 결제 판단용 시험에 '대한민국의 수도'가 나왔다. 이 정도 상식 문제로는 도구 간 차이가 드러나기 어렵다는 게 세로AI의 판단이다. 고칠 점은 이렇다.

- 사실 확인형: 정답을 내가 직접 확인할 수 있는 덜 알려진 사실로 바꾼다. 자사 제품의 공개 사양, 내 업무와 관련된 법령 조항의 시행일 같은 것.
- 최신 정보형: 평가 당일 정답을 직접 확인해 둬야 채점할 수 있다.
- 비교형: 범위가 넓다. 기간이나 국가를 정해 주면 비교가 쉬워진다.

### 15점 채점표

1, 2번 항목은 테스트 결과에서 가져왔고, 3번부터 5번은 세로AI가 채점용으로 정했다. 항목마다 통과 1점, 실패 0점이니 질문당 최대 5점, 세 질문이면 5 × 3 = 15점 만점이다. 표로 둔 이유는 하나다. 복사해서 오른쪽 칸에 바로 점수를 적으라는 것.

| 항목 | 통과 기준 | 최신 | 비교 | 사실 |
|---|---|---|---|---|
| 1. 링크 작동 | 눌러 보면 오류 없이 열린다 | | | |
| 2. 본문 내용 일치 | 핵심 주장이 링크 본문에 있다 | | | |
| 3. 출처 수준 | 1차 자료이거나 출처를 밝힌 매체 | | | |
| 4. 날짜 | 오래된 자료를 최신처럼 쓰지 않는다 | | | |
| 5. 중복 | 여러 링크가 한 기사를 옮긴 게 아니다 | | | |

## 무료로 충분한지 가르는 4단계

1. 질문 3개를 내 업무 주제로 바꾼다.
2. 무료, 기본 설정으로 평일 5일 써 본다.
3. 15점 채점표로 채점한다.
4. 부족한 쪽이 품질인지 한도인지 나눈다.

### 1단계: 내 질문으로 바꾸기

위 프롬프트에서 주제만 바꿔 다시 돌려도 된다. 완성한 문구는 메모장에 저장하고 매번 복사해 붙여 넣는다. 문구가 한 글자라도 달라지면 비교가 흐려진다.

### 2단계: 무료로 실제 업무에 쓰기

세로AI는 평일 5일 정도를 권한다. 사용이 막히거나 한도 안내가 뜨면 화면을 캡처하고 날짜, 시각, 그날 몇 번째 질문이었는지 적는다. '횟수가 부족한가'를 판단할 가장 확실한 근거가 이 기록이다.

### 3단계: 채점과 판정

판정 규칙은 세 줄이다.

- 질문별 4점 이상이면 통과
- '본문 내용 일치'가 실패면 점수와 상관없이 그 질문은 실패
- 3개 중 2개 이상 통과면 품질은 무료로 충분

4점 컷은 한 항목 감점까지는 봐주되 본문 일치는 양보하지 않겠다는 뜻이다. 세로AI가 정한 기준이니 업무에 맞게 조정해도 된다. 주장의 일부만 본문에 있으면 '본문 내용 일치'는 실패로 친다. 관대하게 채점할수록 결제 판단이 흐려진다.

예: 5점, 4점, 3점이면 2개 통과, 품질 충분. 단 4점짜리가 본문 일치에서 깎인 게 아니어야 한다.

### 4단계: 품질이냐 한도냐

- 한도 안내 없음, 품질 통과: 무료를 유지한다.
- 품질 통과, 한도 안내가 업무를 끊음: 아래 7가지 중 무료 범위, 요금제, 결제부터 본다.
- 품질 미달: 모델을 바꿔 같은 질문을 다시 돌린다.

기본 설정으로 통과했다면 모델을 바꿀 이유가 없다. 바꿀 때는 질문 입력창 주변과 설정 메뉴에서 모델 선택 항목을 찾고, 보이지 않으면 도움말 센터에서 '모델', 'model'로 검색한다. 바꾼 모델로 점수가 오르는지만 보면 된다.

## 결제 직전 공식 페이지에서 확인할 7가지

찾을 곳은 perplexity.ai의 요금 안내 페이지, 로그인 뒤 계정 설정, 도움말 센터다. 아래 검색어는 도움말 센터에서 써 볼 제안이다.

앞의 셋은 놓치면 엉뚱한 요금제를 사거나 나중에 돈이 빠져나가는 항목이다.

### 1. 점수를 올린 모델이 그 요금제에 있나

- 어디서: 요금 안내 페이지의 비교 항목, 검색어 '모델'·'model'
- 볼 것: 4단계에서 점수를 올린 모델이 내가 살 요금제에 들어 있는지

### 2. 대학생 혜택이 끝난 뒤

- 어디서: 도움말 센터, 검색어 '학생'·'student'
- 볼 것: 대상, 인증 절차, 혜택 기간, 종료 후 요금. 종료 뒤 자동 결제 여부를 화면으로 캡처하고 종료일을 캘린더에 적는다.

### 3. 최종 총액과 해지 메뉴

- 어디서: 결제 화면, 계정 설정
- 볼 것: 결제 통화와 세금이 반영된 최종 총액을 캡처한다. 해지 메뉴는 결제 전에 찾아 둔다.

### 나머지 넷

- 무료 범위와 한도: 요금 안내 페이지, 검색어 '한도'·'limit'. 2단계 캡처와 공식 설명을 대조한다.
- 요금제 이름과 가격: 블로그에서 본 요금제 이름이 지금 없으면 그 블로그의 숫자는 버린다.
- Comet 브라우저: 도움말 센터, 검색어 'Comet'. 무료 여부와 내 OS 지원 여부를 설치 전에 본다.
- 가입 조건과 변경 공지: 계정, 지역, 연령 조건. 변경일이 참고한 글의 작성일보다 뒤라면 그 글의 숫자는 믿지 않는다.

## FAQ

### Q1. 퍼플렉시티 유료 요금은 얼마인가요?

이 글에는 숫자를 싣지 않았다. 블로그의 숫자 대신 결제 직전 요금 안내 페이지와 결제 화면에 찍힌 총액을 기준으로 삼는다.

### Q2. 이 질문 세트는 다른 검색형 AI에도 쓸 수 있나요?

쓸 수 있다. 프롬프트에 특정 도구의 기능이 들어 있지 않으니 같은 질문과 같은 채점표로 여러 도구를 비교하면 된다. 요금제가 바뀌어도 세트는 그대로 다시 쓴다.
