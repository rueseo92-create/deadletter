강의 영상 중반, 강사가 "이제 Claude Code를 켜 볼게요"라고 말하면 무료 플랜 사용자는 거기서 멈춰야 해요. 공식 가격표의 Claude Code 칸에 Free는 "No"로 표시돼 있거든요.

> 핵심 답변: Free 플랜에서는 Claude Code를 쓸 수 없어요. Pro·Max·Ultra 구독에서는 쓸 수 있어요.

퀵스타트 문서는 구독 외에 Claude Console 계정이나 지원되는 클라우드 제공자 접근도 계정 조건으로 안내해요. 무료 사용자가 이 경로로 쓸 수 있는지, 비용이 얼마인지는 확인하지 못했어요. 가격표에는 개발자용 API를 따로 과금한다고 나와 있어요. 이 경로를 생각한다면 공식 문서에서 비용 조건부터 확인하세요.

## 채팅·Design·Slides·Docs는 무료, Claude Code만 막힌다

Free는 누구나 무료로 쓸 수 있고, Claude Design, Slides, Docs도 열려 있어요. 그래서 채팅과 문서 작업을 다루는 강의 앞부분은 Free로 따라갈 수 있다고 봐요. 이건 제 해석이에요. (출처: Claude Plans & pricing)

| 플랜 | Claude Code |
|---|---|
| Free | 안 됨 |
| Pro | 됨 |
| Max | 됨 |
| Ultra | 됨 |

사용량은 가격표 문구만 옮길게요. Pro는 Free보다 5시간 세션당 최소 5배예요. Max는 Pro의 5배를 5시간마다, 그리고 매주 줘요. Ultra는 주간 사용량이 Pro의 10배예요. 배수의 기준이 서로 달라서 플랜끼리 곱해 비교하지는 않았어요.

Pro 한도는 5시간 한도와 전체 모델에 걸리는 주간 한도로 이뤄져요. (출처: Claude Help Center)

월 요금, 한국 결제 통화, 부가세는 확인하지 못했어요. 요금제와 한도는 바뀔 수 있고, 강의를 녹화한 시점과 지금이 다를 수 있어요. 결제 직전에 claude.com/pricing에서 직접 보세요.

## 강의 따라가는 3단계: Free로 시작, Code 구간에서 멈춤, Usage 확인

1. claude.ai에서 Free로 시작해요. 강의 앞부분을 따라 하다가 한도에 자주 걸리면 그때 올려도 늦지 않아요.
2. Claude Code 구간이 나오면 영상을 멈추고 플랜을 확인해요. Free라면 여기서부터는 Pro 이상 구독이 필요해요.
3. 유료로 올렸다면 Settings > Usage의 진행 막대로 남은 사용량을 봐요. 공식 안내 대상은 Pro, Max, Ultra, Team, 좌석형 Enterprise이고, Free는 목록에 없어요. (출처: Claude Help Center)

참고로 Claude.ai는 만 18세 이상만 쓸 수 있어요. 170개국 이상에서 서비스되지만, 한국이 포함되는지는 확인하지 못했어요. (출처: Anthropic Transparency Hub)

## 클로드 코드 사용법 강의 전 준비물 3가지: 터미널·프로젝트·계정

터미널, 작업할 코드 프로젝트, 계정이 필요해요. 계정은 Claude 구독, Console 계정, 지원되는 클라우드 제공자 접근 중 하나면 돼요.

퀵스타트 순서는 단순해요. CLI를 설치하고, 첫 세션에서 로그인한 다음, 프로젝트 폴더에서 `claude`를 실행하면 시작돼요. OS별 설치 명령어는 정확한 문구를 확인하지 못했어요. 강의 화면 속 명령어를 그대로 치지 말고 공식 퀵스타트의 최신 명령어를 복사해 쓰세요. (출처: Claude Code Docs)

### 터미널이 부담스러우면 데스크톱 앱 Code 탭부터

터미널을 처음 쓴다면 공식 문서도 터미널 가이드부터 보라고 안내해요. 더 쉬운 길도 있어요. 데스크톱 앱에는 Claude Code가 들어 있어서, 앱을 실행해 로그인한 뒤 Code 탭을 누르면 바로 시작돼요. 따로 설치할 것도 없어요.

이 밖에 웹(claude.ai/code), VS Code, JetBrains, Slack, GitHub Actions, GitLab에서도 쓸 수 있어요. JetBrains에서는 Cmd+Esc(Mac)나 Ctrl+Esc(Windows/Linux)로 바로 열려요. (출처: Claude Code Docs)

## 자주 하는 실수: 한 대화를 끝없이 이어 가기

공식 문서는 보낼 수 있는 메시지 수가 메시지 길이, 첨부 파일 길이, 대화 길이에 따라 달라진다고 해요. 정해진 숫자는 없다는 뜻이에요. (출처: Claude Help Center)

그래서 주제가 바뀌면 새 대화로 시작하는 편이 한도 관리에 유리하다고 봐요. 이건 제 해석이에요.

## FAQ

### Q1. Team이나 Enterprise 플랜에서도 Claude Code를 쓸 수 있나요?

가격표에서 두 플랜의 Claude Code 표시는 확인하지 못했어요. 다만 Claude Code 퀵스타트 문서는 두 플랜을 쓸 수 있는 계정으로 안내해요.

### Q2. 가격표에 최근 바뀐 내용이 있나요?

Ultra의 API 크레딧 $200 증액이 "New"로 표시돼 있는 것까지 확인했어요. 바뀐 날짜는 확인하지 못했어요.
